# Morning Digest Automation

A [[llm-wiki-pattern]] extension in which a scheduled script runs [[claude-code]] every morning to surface open tasks, new sources, and a daily briefing — making the second brain proactive rather than purely reactive.

---

## Explanation

The morning digest is a cron job that runs automatically each day (typically at 7:30am) without user intervention. It reads a `Memory.md` file (the user's context file), surfaces any open actions due that day, scans for new files added to raw sources in the last 24 hours, and prints a clean briefing to the terminal. It is set up once via a Claude Code prompt and then runs indefinitely.

---

## Setup Prompt (from [[defileo-claude-obsidian-second-brain]])

```
claude -p "Write a Python script called morning_digest.py that:
1) reads Memory.md and surfaces any open actions due today
2) reads any new files added to /raw-sources in the last 24 hours
3) prints a clean briefing to the terminal.
Then schedule it as a cron job every morning at 7:30am." --allowedTools Bash,Write
```

---

## Why It Matters

Most [[second-brain]] systems are passive — you have to remember to open them. The morning digest flips this: the system comes to you. It also creates a daily forcing function for reviewing open actions and new material, which is the key habit that makes a second brain stay current rather than decay. The automation eliminates the friction that causes the habit to lapse.

## How Sources Treat This Concept

[[defileo-claude-obsidian-second-brain]] introduces this as a "set it once, runs forever" automation and frames it as one of the key differentiators of the LLM-maintained wiki over passive note systems. The full Python script is generated by Claude on demand — it is not provided in the source.
